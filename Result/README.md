# Saved design runs

**VI:** Mỗi thư mục con là một snapshot artifact cho một thiết kế hoặc lần chạy. Xem README trong snapshot để biết có RTL, SVA, testbench, báo cáo và log nào; không coi file báo cáo đơn lẻ là bằng chứng pass.

**EN:** Each subfolder is an artifact snapshot for a design or run. See its README for available RTL, SVA, testbench, reports, and logs; a report file alone does not establish a pass.
