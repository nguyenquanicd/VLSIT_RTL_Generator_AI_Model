# VLSIT workflow skills

**VI:** Mỗi thư mục con chứa một SKILL.md cho một phase: soạn và phân tích spec, cấu hình, RTL, SVA, testbench, verification, PDF hoặc autoflow. Gọi skill bằng tên thư mục trong Codex CLI và đọc SKILL.md tương ứng trước khi chạy.

**EN:** Each subfolder contains a SKILL.md for one phase: spec writing and parsing, configuration, RTL, SVA, testbench, verification, PDF, or autoflow. Invoke a skill by its folder name in Codex CLI and read its SKILL.md before running it.
